Why the site appears blank

This is a React SPA built with Vite — it cannot be opened by double-clicking index.html in a browser. It needs a server to process the module imports. Run npm install then npm run dev to see it. Additionally, ServicePackages.jsx is truncated — the file ends mid-component, which will throw a parse error and crash the entire app.
